# עריכת הצ'קליסט — למנהל

תוכן הצ'קליסט נשמר ב-Supabase, כך שאפשר להוסיף / לשנות / להוריד פריטים **בלי מתכנת
ובלי לפרוס מחדש**. השינוי מופיע לעובדים בפעם הבאה שהם פותחים את האפליקציה.

> רק לך (בעל חשבון ה-Supabase) יש גישה לעריכה. העובדים יכולים רק לקרוא את הרשימה.

## איפה עורכים

1. היכנס ל-[supabase.com](https://supabase.com) → הפרויקט שלך.
2. בתפריט הימני → **Table Editor**.
3. יש שתי טבלאות רלוונטיות:
   - **`checklist_items`** — הפריטים עצמם.
   - **`checklist_settings`** — ההערה העליונה והגרסה.

## טבלת `checklist_items` — העמודות

| עמודה | מה זה |
|-------|-------|
| `section` | שם הסעיף (למשל "אולם 1"). פריטים עם אותו שם סעיף מקובצים יחד. |
| `label` | הטקסט של הפריט שהעובד רואה. |
| `position` | מספר שקובע את **הסדר**. קטן = מופיע קודם. |
| `active` | האם הפריט מוצג. כדי להוריד פריט — שנה ל-`false` (עדיף על מחיקה). |

## פעולות נפוצות

**להוסיף פריט חדש**
- לחץ **Insert → Insert row**, מלא `section`, `label`, ו-`position`.
- כדי שהפריט יופיע במקום הנכון, תן לו `position` בין שני הפריטים השכנים
  (למשל בין 20 ל-30 → שים 25).

**לשנות טקסט של פריט**
- לחץ על התא של `label`, ערוך, שמור.

**להוריד פריט**
- ערוך את השורה, שנה `active` ל-`false`. (הפריט נעלם מהאפליקציה אבל נשמר.)

**לשנות שם של סעיף שלם**
- ערוך את `section` בכל השורות של אותו סעיף לאותו שם חדש.

**לשנות סדר**
- שנה את מספרי ה-`position`. הרשימה מסודרת מהקטן לגדול.
- טיפ: הפריטים נבנו עם קפיצות של 10 (10, 20, 30…) כדי שיהיה קל להכניס באמצע.

**חשוב:** שמור את כל הפריטים של אותו סעיף עם מספרי `position` **רצופים** (בלי
שסעיף אחר "ייכנס באמצע"), אחרת הסעיף יתפצל לשתי כותרות.

## טבלת `checklist_settings`

| `key` | `value` |
|-------|---------|
| `top_note` | ההערה הצהובה הבולטת בראש המסך. |
| `checklist_version` | גרסת הצ'קליסט שנשמרת עם כל סגירה. בַּמֵּף (למשל ל-`v2`) כשאתה עושה שינוי משמעותי, כדי שיהיה תיעוד איזו גרסה הייתה בתוקף בכל סגירה. |

## רשת ביטחון

אם הטבלה ריקה או שאין חיבור לרשת, האפליקציה נופלת אוטומטית לרשימה הקבועה שבקוד —
כדי שאף פעם לא ייחסם עובד מלסגור את המפעל.
